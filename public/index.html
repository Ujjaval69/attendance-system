🔒 Robust Authentication

Enterprise Security Protocols

Your data protection is built into the architecture. We use industrial-grade safeguards at every layer.

🔐 Token-Based Auth (JWT)

All sessions are signed using cryptographically secure JSON Web Tokens. Credentials are stored securely and never transmitted in raw format.

🛡️ Role Verification

Granular authorization gates verify whether a user is an administrator or student before validating server requests, blocking injection attempts.

🔑 Secret Key Gatekeeper

Administrative signups require validation using a unique invitation secret key, stopping unauthorized personnel from accessing control panels.

❓ Clear Answers

Frequently Asked Questions

Everything you need to know about the platform controls and operation.

How does the student/admin registration work?
Registration is separated by roles. To register as an Administrator (Teacher), you must enter a pre-configured Admin Secret Key. Students can sign up freely but will only access the read-only attendance panels matching their specific email accounts.
What is the 30-Day Grid heatmap?
It is a contribution calendar grid similar to GitHub's code activity feed. It displays your last 30 calendar days of classes: Green represents a day you were present, Red means absent, Yellow is late, and Grey means no classes were scheduled for that day.
Can educators export records for spreadsheets?
Yes! Inside the Records section, admins can filter by student email, subject, or dates, and click the Export CSV button. The application will instantly format the active search table rows into a CSV spreadsheet file and trigger a browser download.
How do I test the dashboard with sample statistics?
Inside the admin panel, pick a student email, enter their name, and click the ✨ Seed Demo Data button. The app will generate 15 realistic historical attendance records spread over the past month, immediately populating the heatmap grid, doughnut/bar charts, and progress bars.
